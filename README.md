# RootOS 🖥️

A fake desktop/OS that runs in your browser.

## What is this?

I made RootOS because I wanted to make a website that feels a bit like an old computer.

It has windows that you can move around, a taskbar, start menu and some small apps.

## Stuff in it

* Draggable windows
* Taskbar + clock
* Start menu
* Terminal
* Notepad
* Calculator
* DevLogs
* System info

## Made with

* HTML
* CSS
* JavaScript

No frameworks or anything like that.

## Run it

Clone the repo:

```bash
git clone [https://github.com/itzdeep2/RootOS.git](https://github.com/itzdeep2/RootOS.git)
cd RootOS```

Then open `index.html`.

That's basically it.

## Why I made it

I just wanted to try making a small OS-like UI in the browser.

It was also a fun project to work on because I got to make the windows and little apps myself.
